# Analyzer — checklist diagnostica

Per ogni prompt in input, compila queste voci.

## 1. Intento
- Obiettivo dichiarato:
- Obiettivo implicito (inferito):
- Destinatario dell'output:

## 2. Struttura
- [ ] Ruolo/persona definito
- [ ] Contesto sufficiente
- [ ] Task singolo e non ambiguo
- [ ] Vincoli espliciti (lunghezza, tono, lingua, formato)
- [ ] Formato di output specificato
- [ ] Criteri di successo verificabili
- [ ] Esempi (few-shot) presenti e coerenti

## 3. Rischi
- Ambiguità lessicali:
- Istruzioni contraddittorie:
- Assunzioni non verificate:
- Rischio di allucinazione (richieste fattuali senza fonti):
- Rischio di over-length / troncamento:

## 4. Output dell'analisi
1. Sintesi in 3 righe.
2. Elenco puntato dei difetti, ordinati per impatto.
3. Domande di chiarimento (max 5), solo se bloccanti.
4. Prompt riscritto.
