# Grader — rubrica 0-100

## Dimensioni (20 punti ciascuna)
1. **Chiarezza** — il modello può eseguire senza chiedere chiarimenti.
2. **Contesto** — tutte le informazioni necessarie sono presenti.
3. **Formato** — struttura di output definita e verificabile.
4. **Vincoli** — limiti, tono, lingua, cosa escludere.
5. **Verificabilità** — criteri di accettazione misurabili.

## Scala per dimensione
- 0-4 assente · 5-9 accennato · 10-14 parziale · 15-17 buono · 18-20 eccellente

## Fasce finali
- 90-100 production-ready
- 75-89 solido, ritocchi minori
- 60-74 utilizzabile con revisione
- <60 da riscrivere

## Output
Tabella dimensione / punteggio / motivazione (1 riga) + totale + le 3 azioni a maggiore impatto.
